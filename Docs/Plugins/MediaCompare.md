# AB 审片插件

需求与设计；当前实现、产物和验证结果统一见[开发台账](../DEVELOPMENT.md#media-compare)。

## 范围与交互

- 左 A、右 B，各自打开本地视频、单图或显式选择的编号图片序列。普通图片不会自动推断为序列。序列帧率由用户指定；缺帧应报错，不悄悄跳号。
- 共同时间轴控制播放、暂停和定位；A/B 可采用不同编码、尺寸与帧率。按共同时间映射各自画面，不把两个文件相同帧号当作同一时间。精确前后逐帧需要邻帧时间索引，当前不以名义 FPS 加减冒充逐帧。
- 两边共用归一化图像中心与缩放比例，保留各自宽高比；适合窗口与原始像素是不同模式。原始像素按实际显示像素计算，不能把 DIP 当作设备像素。
- 声音选择静音、只听 A、只听 B。时间轴上限取两边媒体估计时长的较短者；容器可能包含仅音频尾段，定位无视频帧时立即提示。单图持续保留，不限制另一边的视频时长。
- 拖动时暂停播放，以单个在途解码及单个最新待处理位置节流；连续拖动期间可显示中间采样画面，松手取消旧请求并定位最终位置。滑块为请求时间，预览异步到达；不承诺移动中的滑块与正在提交的 GPU 帧同时更新。PR 式流畅度属于待实测目标，不能由库名、GPU 标志或构建成功推定。
- 长 GOP 素材的逐帧代理、邻域缓存、前后邻帧索引及素材时间偏移是后续性能/对齐工作，不能用低分辨率代理冒充原片细节。当前操作必须显示实际支持情况。

## 依赖与宿主边界

采用官方 GStreamer 1.28.9 的公开 C ABI 与 D3D11 能力，不修改上游，不引入完整 GES 剪辑模型。运行库与 GPU 互操作库是插件私有依赖，随插件交付；不依赖系统 PATH、另装播放器或 Python 环境。

只引用公开 Contracts/UI；媒体引擎、时间映射、GPU 资源与缓存均归插件。注册页使用现有 Avalonia 控件能力；若必须修改宿主、Core、Contracts 或公共 UI，停止该项实现并交由架构侧分析。包体仍遵循[现有安装限制](../PLUGIN_DEVELOPMENT.md#3-运行目录与打包)。

## 内部职责

| 部分 | 责任 |
| --- | --- |
| `ComparePlugin` | 轻量初始化、页面注册、插件停止 |
| `Media/ComparisonSession` | 共同时间、播放状态、定位作废、帧配对及资源释放 |
| `Native/Interop` | 固定版本 C ABI、私有 DLL 初始化，不向宿主泄漏原生接口 |
| `Rendering`、`Views/ComparePreview` | 将 A/B 合成为一张 GPU 画面、共享纹理同步、联动视图 |
| `CompareViewModel`、`CompareView` | 用户操作、素材选择、时间轴、状态与页面订阅 |

原生样本由有界持有者管理；画面提交后复制到插件纹理，暂停/缩放不持续占用解码表面。UI 更新合并，不能将每一帧都无限排入 Dispatcher。共享时钟不等于自动同帧呈现，配对与最终提交由插件负责。

## 失败与生命周期

- 无运行库、缺解码器、损坏/不可读素材、超时、显卡不兼容均给出原因，不展示模拟帧。
- 当前解码器与 Avalonia 必须使用同一 GPU；使用公开的 D3D11 共享纹理接口，不支持软件渲染后端或跨 GPU 纹理转移。预览失败会暂停声音与解码，恢复前禁用播放。
- 格式覆盖以实际分发的解码模块为准。初始 BGRA8 显示路径不代表具备 HDR、16-bit 或浮点审片精度；未实现的色彩路径必须明确拒绝，不能静默当作原片正确显示。
- 源端同步检查第一份格式；后续非等价格式或色彩标记变化会锁存错误并阻断数据，定位产生的重复等价格式允许通过。缺失/错误元数据不能证明素材不是 Log，也不等于已经做了显示器色彩校准。
- 替换素材失败应保留原先有效会话；定位取消不记录 Error，不提交过期画面。
- 切页解除显示订阅并暂停交互播放，保留已打开素材与位置；这不是取消后台转码任务。当前没有代理转码后台任务。
- 停止先取消并等待媒体操作，再释放解码样本、图形和管线；不调用进程级 `gst_deinit`，不强杀宿主。

## 验收方法

1. 两条带帧号/时间码和同步音频标记的素材：共同播放、暂停、反复拖动、时间轴键盘定位、末尾及仅音频尾段；核对实际画面时间，不能只看滑块。
2. 中文/空格/百分号路径、静态透明图片、编号序列、缺号序列、24/25/30 fps 以及可变帧率；拒绝损坏文件后再次打开正常文件。
3. 不同宽高比和分辨率：滚轮光标锚点、归一化中心、联动平移、适合窗口、1:1、125%/150% DPI、缩放窗口。
4. 静音/A/B 声音切换、无音轨素材；切页重返、隐藏到托盘、连续替换、播放中退出，检查原生资源与日志。
5. 双 4K 长 GOP 正倒拖，记录冷定位/缓存定位延迟、丢帧和显存占用；普通可播放不能代替性能验收。
6. 从独立 ZIP 安装到干净宿主，不依赖开发机运行库；检查私有 DLL、许可、压缩/展开体积及平台限制。

自动化纯托管检查覆盖样本所有权、视图数学与序列文件校验，不替代上述真实媒体、Windows、GPU 和 UI 验收。
