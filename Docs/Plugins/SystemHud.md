# 桌面状态 HUD 插件

参考 zmd-charge-plus 的使用场景，在本项目 .NET 10 / Avalonia 12.1.2 环境下独立实现。入口为 [HudPlugin](../../Plugins/TractorTool.Plugins.SystemHud/HudPlugin.cs)，当前进度及证据只见 [开发台账](../DEVELOPMENT.md#current-status)。

## 范围与接入

按用户确认分三步推进：

1. 基础 HUD：电量/插拔电源提醒、时钟、CPU/内存/网速，动画、屏幕位置与缩放、点击穿透、托盘操作。
2. 多方案、轮播、变量模板、颜色规则、编辑和预览。
3. GPU/温度/硬件传感器、网络探测、HTTP/JSON、DeepSeek 和更多变量。

通过现有页面注册接口提供“桌面状态 HUD”主页面，以及“设置 → 插件设置 → 桌面状态 HUD”；不新增导航 API。打开软件仍复用现有托盘“显示 TractorTool”。两个页面使用宿主共享样式；桌面 HUD 使用插件内的黑色胶囊与方案强调色，不覆盖其他页面样式。没有复制参考仓库的代码、美术、字体或动画资源。

| 入口 | 职责 |
| --- | --- |
| 插件主页面 | 左侧“状态预览”呈现运行状态、常用动作和最近读数；右侧“显示方案”编辑指标、来源、轮播、模板、颜色和预览；窄窗口改为整页纵向滚动 |
| 插件设置 | 启用、默认常驻、电源提醒、点击穿透、动画、硬件传感器及 HUD 大小；独立保存/清除 DeepSeek 凭据 |
| 托盘子菜单 | 复用主页面的显示/隐藏、暂停/恢复、预览操作，以及临时切换下一方案；启动失败或关闭 HUD 时禁用 |

公开接入只依赖 Contracts 1.7 / UI 1.5；Avalonia 由宿主共享。MVVM 和 LibreHardwareMonitorLib 0.9.6 及其运行依赖是插件私有 NuGet 依赖，随 ZIP 分发并保留许可及源码来源，见 [NOTICE](../../Plugins/TractorTool.Plugins.SystemHud/NOTICE.md)。没有新增 Core 服务、公共接口、独立进程或驱动安装能力。访问被拒绝时明确显示需要管理员权限，由用户自行退出并以管理员身份运行。

## 第一版内部职责设计

第一版按上述三步的核心能力交付，后续优先允许修改界面和交互，不承诺复制参考程序的全部变量、脚本表达式、桌面嵌入或品牌动画。

源码物理目录按职责分为 `Configuration`、`Sampling`、`ViewModels`、`Views`；入口、工程及清单保留根目录，AXAML 与对应后台文件成对存放。完整目录树与阅读顺序见 [源码导航](../../Plugins/TractorTool.Plugins.SystemHud/README.md)。目录整理保留原命名空间，不改变清单入口、持久化格式或业务行为。

| 部分 | 所有权与修改边界 |
| --- | --- |
| [HudProfile](../../Plugins/TractorTool.Plugins.SystemHud/Configuration/HudProfile.cs) / [HudSettings](../../Plugins/TractorTool.Plugins.SystemHud/Configuration/HudSettings.cs) | 配置、校验与稳定标识；不执行 I/O 或创建窗口。新字段带默认值，原指标编号 0–4 不重排 |
| [HudSampler](../../Plugins/TractorTool.Plugins.SystemHud/Sampling/HudSampler.cs) / WindowsMetrics / [NetworkMetrics](../../Plugins/TractorTool.Plugins.SystemHud/Sampling/NetworkMetrics.cs) / [HardwareMetrics](../../Plugins/TractorTool.Plugins.SystemHud/Sampling/HardwareMetrics.cs) | 单次读取返回 HudReading 和可展示失败原因；超时、请求缓存、资源释放。更换硬件库或增加具体来源主要改这里，不改变页面协议 |
| [HudModel](../../Plugins/TractorTool.Plugins.SystemHud/ViewModels/HudModel.cs) 及 Profiles / Sources 分部 | 单一 VM 按职责拆文件：运行协调、方案编辑、传感器检测和凭据操作；取消/迟到隔离、电源优先和轮播。页面不直接访问采集器 |
| [HudPresentation](../../Plugins/TractorTool.Plugins.SystemHud/Views/HudPresentation.cs) / HudCard / HudView / HudSettingsView / HudWindow | 读数转显示、模板与颜色、页面和窗口布局；更改视觉主要改 AXAML，更改操作流改 VM，不改采集器 |
| [HudSecrets](../../Plugins/TractorTool.Plugins.SystemHud/Configuration/HudSecrets.cs) | 当前 Windows 用户 DPAPI 加解密；凭据与可编辑方案分开，网络层仅取得本次请求所需的内存密钥 |

数据流为 `保存的方案/草稿快照 → 单次采样 → HudReading → 模板呈现 → HudCard`。窗口和采集资源属于插件实例，页面只是编辑入口；没有另建服务容器、采集插件系统、通用表达式引擎或后台监控平台。隐藏 HUD 不销毁页面草稿；显示未读到数据时明确未知，失败不继续把旧读数当新数据。

界面参考 [Apple HIG Layout](https://developer.apple.com/design/human-interface-guidelines/layout) 的视觉层级、对齐分组与逐步展开原则，以及 [Settings](https://developer.apple.com/documentation/foundation/adding-a-settings-interface-to-your-app) 的使用频率分工：主页面保留状态与常用动作，复杂模板/来源配置按当前选择展开；位置直接拖动桌面 HUD 调整。长期偏好、缩放、硬件启用与账号凭据放插件设置。保留宿主 Windows/Avalonia 控件与主题，不照搬 macOS 窗口外观。

主页面扣除两侧 28 DIP 留白后的可用宽度至少 900 DIP 时采用左右结构：左侧 400 DIP 状态与预览，右侧占剩余宽度编辑；两栏使用同字号、同高度标题，标题下分别滚动，不让预览展开消耗编辑区高度。更窄时沿用同一组控件上下排列，只启用整页滚动，关闭栏内滚动；按 [Apple HIG Scroll views](https://developer.apple.com/design/human-interface-guidelines/scroll-views) 避免同方向嵌套滚动。复用既有 UsesCustomHeader 注册选项，页面自身管理标题和内容留白，窄窗口滚动条位于页面最右边；未改公共 UI。方案操作与表单一起滚动，低高度下仍可访问；页面预览卡片允许向下缩放，不改变真实 HUD 大小。断点只调整布局，不重建页面、切换方案或清空草稿。

## 交互

桌面和两处预览共用 HudCard：紧凑态为 360 × 60 DIP 的深色横条，左侧为指标对应的线条图标，中间为方案数值，右侧为百分比环与展开箭头；非百分比指标只显示箭头，不伪造进度。点击摘要后展开为 360 × 224 DIP，在原摘要下显示完整标题、数值和说明，长内容可滚动；再次点击收起。保留原模板和规则色，紧凑长文省略、悬停可读全文。设计采用参考软件的横向信息层级，以及 Apple Live Activities 的紧凑/展开分工；调研来源和固定提交见 [E75](../PROJECT_HISTORY.md#evidence-hud-compact-interaction)。不复制参考程序或 Apple 的源码、图形、字体和动画资源。

摘要使用原生 ToggleButton，提供展开状态、可访问名称、悬停/按下和键盘焦点反馈；页面预览支持键盘切换，桌面窗口沿用不抢焦点行为。拖动只监听摘要，移动任一轴达到 6 DIP 才取消按钮点击并进入原生移动；详情区不接管指针，滚动和后续具体按钮可使用普通控件。当前只实现展开/收起，没有无消费者的动作接口或空按钮。展开为临时状态，不写配置；底部空间不足时向上避让，收起恢复原紧凑锚点。实际拖动后保存新的位置。尺寸由 HudSettings.CardWidth/CardHeight/ExpandedHeight 与卡片布局对应，不更改配置 schema。

- 默认启用、非常驻；插入/拔出电源时显示电量 6 秒，电量变化更新已显示内容，无电池/未知状态显示明确说明。
- 常驻显示当前方案的单项指标；托盘可临时显示/隐藏、暂停更新、预览 6 秒、切换下一方案。托盘临时操作和自动轮播不写配置；重启以最后一次“保存并使用”的方案为准。
- 默认关闭点击穿透，按住桌面 HUD 摘要超过移动阈值后用系统原生操作拖动，结束时保存一次位置；小幅抖动仍作为点击，不轮询鼠标或持续写配置。不再提供“窗口位置”页、显示器/锚点/偏移编辑或保存位置按钮。HUD 大小在插件设置中调整，范围 0.6–2 倍。
- 拖动位置保存为屏幕显示名称、编号及可移动工作区内的相对坐标；恢复时考虑卡片尺寸和 DPI，目标屏幕名称找不到时退回主屏。显示名称不是硬件唯一标识，重名屏幕取首个匹配项。旧配置的显示器/锚点/偏移仅作首次拖动前的兼容回退。超出工作区时钳制；工作区比卡片小时钉在原点，不能保证整个卡片放得下。
- 不抢焦点、不在任务栏增加入口、置顶。开启点击穿透后收起详情，鼠标操作下方窗口，不能点击或拖动；已有配置中显式开启的穿透偏好保留，主页面提示去设置关闭。隐藏使用主页面或托盘动作，隐藏后重置为紧凑态；不是嵌入 Explorer 桌面层。
- 出现时淡入；插件动画开关与宿主“界面动画”设置共同生效。关闭动画不影响数据显示。
- 主页面“保存并使用”只保存方案及轮播；拖动只保存共用位置；设置页“保存偏好”保存六项开关及缩放，密钥独立保存/清除。不提交或清空其他区域的草稿。位置写入失败恢复上次持久化位置并提示错误。拖动或展开详情期间暂停预览到期与轮播，读数仍按原频率更新；拖动结束且已收起后，原预览重新计时 6 秒。显式隐藏、关闭或取消预览仍生效。
- 主页面只展示 HUD 最近读数，不另启一份性能采样。启动失败显示原因并禁用控制，保留配置编辑供修复后重启；详细异常由宿主统一记录。

## 方案、模板与预览

- 最多 32 个方案，支持新增、复制、重命名、编辑和删除，至少保留一个。选择下拉项只载入编辑区；“保存并使用”才提交并应用。新增/复制/删除先保存成功再更新列表；有草稿时先保存或撤销再切换方案，不暗中丢弃编辑。
- 每个方案选择一个指标，配置标题/数值/说明三个文字模板和基础颜色。变量支持 `{label}`、`{value}`、`{detail}`、`{percent}`、`{name}`、`{unit}`、`{updated}`；单位仅在指标有统一单位时提供，无读取时间则显示未知。只替换当前指标数据，不执行脚本、表达式或递归插值。模板最多 60/80/160 字符；紧凑态只展示数值，展开后读完整内容。错误模板或颜色阻止保存和桌面预览。
- 颜色使用 `#RRGGBB`。每个方案提供一个百分比阈值规则，选择低于等于或高于等于，满足时改变数值、图标和进度环颜色；用于电量/CPU/内存/磁盘/传感器负载/明确声明百分比的 JSON。未知值不按 0 处理，温度/余额/延迟不冒充百分比。首版不做多段规则和混合多指标布局。
- 编辑区复用同一 HudCard 即时展示模板/颜色，明确标记“示例数据”；模板无效时保留上一次有效预览。桌面“预览草稿”读取真实指标、冻结本次草稿快照并显示 6 秒，不写配置；暂停更新时禁用该按钮。到期恢复原方案及最近读数，再按可见状态更新，不把草稿残留当当前方案。
- 可按列表顺序轮播已保存方案，间隔 3–300 秒。隐藏、暂停、关闭、退出、电源提醒或草稿预览时停止轮播；恢复后重新计时，不补跑隐藏期间的轮次。电源提醒结束返回原方案，轮播不改编辑区选择与未保存内容。
- 窗口位置、缩放和六项开关由全部方案共用，避免轮播时在屏幕上跳动。轮播计时用于用户选择的显示切换，不增加后台性能采集或日志刷屏。

## 第一版数据源与限制

| 指标 | 来源 / 使用方式 | 限制与失败行为 |
| --- | --- | --- |
| 电量、时钟、CPU、内存、网速 | 既有 Windows / .NET 采集 | 电源按事件；性能按需每秒读取，未知值不显示假零 |
| GPU / CPU 传感器 | 设置启用后，在方案中“检测传感器”，选具体硬件项目；保存稳定传感器 ID | LibreHardwareMonitor 仅启用 CPU/GPU，不扫描主板/存储等组；硬件/驱动不支持时明确未知，温度等可能需要管理员和已安装 PawnIO。插件不安装驱动、不自动提权 |
| 网络延迟 | 主机/IP + ICMP 或 TCP 端口 | ICMP 无响应不等于离线；TCP 连接不代表业务健康，不支持 UDP 探测 |
| HTTP 服务 | HTTP/HTTPS GET，显示响应头耗时及状态 | 不自动跟随重定向、不携带 Cookies 或登录头；用于公开/本机服务 |
| HTTP/JSON | GET 后以 JSON Pointer 选择单个字段，如 `/data/value`、`/items/0/value` | 支持文字/数字/布尔；响应最多 64 KiB、嵌套 32 层，文本显示最多 160 字符；不执行远端内容。百分比必须是 0–100 数字 |
| DeepSeek 余额 | 设置保存 API Key，方案选择 CNY/USD | 仅官方 `/user/balance`，不调用模型、不推算额度、价格或错峰时段；不支持自定义余额地址 |
| 磁盘 / 系统运行时间 | 本地盘符已用容量及比例 / Environment.TickCount64 | 磁盘只读本地固定或可移动盘，不访问网络共享；不可用显示原因 |

网络类间隔 5–3600 秒，余额至少 60 秒，整次请求（包含响应体）最多 4 秒。仅当前显示方案请求；轮播、隐藏、暂停取消在途请求；按方案缓存本次尝试时间和结果，取消也不绕过刷新间隔。配置或凭据保存后清空缓存并使旧结果失效。失败只在原因变化时记 Warning，恢复记一次 INFO；不把地址查询参数、响应体或密钥写入网络错误日志。

`credentials.json` schema 1 只保存 Windows 当前用户 DPAPI 密文，不放入方案。读取失败保留文件并要求重新输入；先保存成功才替换内存密钥，清除时亦如此。密钥只发送给固定 DeepSeek HTTPS 地址，不放进共享 HttpClient 默认头；换电脑/Windows 用户后需要重新输入。DPAPI 不隔离同用户进程或可信插件，不宣称是防恶意插件的安全沙箱。

第一版不包含任意 HTTP 请求头/登录流程、跨指标模板、脚本表达式、全量硬件变量、价格日程、桌面嵌入、自动更新或单独的后台监控平台；后续根据实际 UI/交互需求逐项增补，不提前扩展宿主。

## 采集与生命周期

电源采用 `RegisterPowerSettingNotification`，监听电源来源和电量百分比；初始化及通知时用 `GetSystemPowerStatus` 读取，无 150ms 电源轮询。注册失败明确提示自动提醒不可用，不悄悄启用后台轮询。

CPU 采用 `GetSystemTimes` 时间差，内核时间包括空闲时间；内存采用 `GlobalMemoryStatusEx`；网速采用 .NET `NetworkInterface.GetIPStatistics` 的收发计数差，使用 Stopwatch 实际间隔。与参考项目的计数器差分思路一致，不移植其 WMI/驱动整套采集代码。首次采样/计数器重置显示未知，不能冒充 0；CPU 大于 64 逻辑处理器时仅覆盖调用线程所属处理器组，界面注明范围。网速为活动非 loopback/tunnel 接口合计，含虚拟网卡时可能重复计数，不宣称是纯互联网流量。

精确的 CPU 使用率和网速需要区间，网络连接变化事件不能替代字节速率采样；内存阈值通知也不是实时占用率。当前本地指标可见且未暂停时，每秒后台读取一次，不重叠；基础指标没有另加 WMI/ETW 查询，硬件库内部实现由其负责。时钟在可见时每秒更新；电量页等待事件。性能与网络轮询分别实际启动时记录一次开发优化 Warning，不逐轮刷屏。硬件检测和单次更新由同一锁串行化，只有显式检测或当前硬件方案采样才打开监控库；隐藏/暂停停止读取，退出释放库资源。

`IPluginBackgroundService` 拥有窗口与通知，切页或隐藏宿主不取消。隐藏 HUD/暂停/换指标使旧采样失效并取消网络请求，下次本地采样重新建立基线。退出先停计时器、注销电源和窗口事件、关 HUD，再等待在途采样/检测结束并释放 HttpClient 和硬件库；Stop 重复调用复用同一任务。正常请求取消被捕获，不记 Error；底层 .NET 仍可能在调试器显示已捕获取消异常。原生硬件调用无法强制取消，退出等待其返回，不虚称有强制退出时限。

配置由宿主 `IPluginSettingsStore` 保存到该插件的数据目录。`hud.json` schema 1 保留位置/偏好及兼容旧版的 Metric；`profiles.json` schema 1 保存方案、默认方案和轮播。首次没有方案文件时，用旧 Metric 建立一个默认方案，不自动改写旧文件。坏文件保留并提示，用户显式保存前只使用内存默认值；两份配置分别原子保存，不构造跨文件事务。不访问宿主配置或其他插件数据，动态数值只在内存中。

## 验收方法

独立插件打包使用已有 [Build-Plugin](../../scripts/Build-Plugin.ps1)，不要复制宿主/Avalonia/.NET 框架 DLL。HUD 需要包含 E66 Win32 框架程序集加载修复的宿主；旧宿主只更新插件仍会失败。HUD 是新增独立插件，首版整包脚本仍只组装原有两个正式插件；完整发行前再决定默认附带范围。

- 使用修正后的宿主安装 ZIP，显式退出重启，在主页面新增/复制/改名/删除、保存并使用；确认重启保留方案，旧位置/偏好/指标被继承，方案/偏好/拖动互不提交其他草稿。
- 检查非法变量/括号、颜色、阈值、名称和轮播间隔提示，草稿保存/撤销后可切换方案，保存失败仍保留旧方案；基础颜色及阈值规则与示例预览/真实 HUD 一致。
- 展开最近读数、文字/颜色和轮播，调整宿主宽高及 100%/150%/200% DPI；常规宽度左右标题对齐，窄窗口整页滚动条靠右边缘，所有操作可达。跨断点保留编辑草稿与所选方案；检查栏底和横向内容不被裁切。
- 检查轮播、托盘下一方案、隐藏/暂停/恢复、电源提醒打断、草稿预览到期及退出；临时切换不写配置，迟到采样不串到下一方案。采样基线未知及无电池不显示假 0%。
- 核对启动失败状态、控制禁用及日志原因；正常启动后确认关闭主窗口、切页继续运行，禁用插件并重启后菜单和 HUD 均消失。
- 插拔电源、休眠恢复、电量改变、无电池桌面机；确认没有伪造百分比或重复弹窗。
- 基础指标及磁盘/运行时长逐一观察，确认暂停/隐藏没有持续采样或日志刷屏；网卡断开/重连不出现负数或尖峰，失败显示未知及原因。
- 设置启用硬件后检测并选择传感器；标准/管理员权限、无 PawnIO、读数缺失、换设备、重复检测、退出检测中分别观察，不将“枚举到传感器”当温度实读成功。
- 用自己允许访问的 HTTP/JSON 服务验证合法字段、缺失/null/对象/错误百分比、超时、重定向、超大响应；轮播切换与暂停不串数据，低于网络间隔的轮播不会重复请求。余额需用户自己的密钥验证；保存、清除、重启及密文迁移失败不泄露密钥、不沿用旧余额。
- 拖动到高低 DPI/负坐标副屏、移出边界、重启、拔掉目标屏幕和改变缩放；核对位置恢复与可见性。拖动 6 秒预览时不能中途隐藏；写入失败恢复旧位置，且不提交未保存偏好或方案。
- 点击穿透、无焦点抢占、隐藏/预览到期、动画开/关、托盘快捷项、重复应用、退出恰逢采样。
- 检查横向摘要在明暗桌面、100%/150%/200% DPI 与 0.6–2 倍缩放下的图标/数值/进度环；桌面与页面预览一致，长模板可省略并在展开区完整滚动阅读，未知/非百分比不显示环。验证单击/小幅抖动/真正拖动互斥、详情滚动不移动窗口、底部展开及收起恢复、展开期间预览/轮播暂停、隐藏和穿透设置优先。页面预览检查 Tab/Space 切换与焦点反馈；不将纯逻辑断言当作原生交互证据。
- [HudChecks](../../tests/TractorTool.HudChecks/Program.cs) 是逻辑及内存 HTTP 检查，覆盖计数/位置、方案/模板/规则、配置往返、JSON Pointer/百分比/边界、余额、凭据路由、缓存及取消。不创建窗口、不读硬件或真实网络。命令 `dotnet run --project tests/TractorTool.HudChecks -c Release` 供获准时执行；编译不等于检查运行通过。
