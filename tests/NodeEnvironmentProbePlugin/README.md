# Node 环境测试插件

1.1.0 仅用于隔离验收，不随正式分发。需要 Contracts API 1.10、Avalonia 12.1.6 的 Windows x64 宿主。

`plugin.json` 沿用 Node 24.22.3、pnpm 10.34.9 和真实 npm `is-number@7.0.0` 的锁定输入及 SHA256。没有自有下载器、安装脚本或 node_modules；随包 `Node/probe.cjs` 是用户点击后执行的业务脚本，使用 `createRequire(<lease.Directory>/package.json)` 导入环境依赖。

## 文件职责

| 文件 | 用途 |
| --- | --- |
| `ProbePlugin.cs` | 注册页面、持有模型并在插件停止时取消和等待 |
| `ProbeView.cs` | 输入、场景、操作、结果及可复制路径/进程输出 |
| `ProbeViewModel.cs` | 按需申请环境、公共任务、取消、结果核对及输入设置 |
| `Node/probe.cjs` | 实际数值判断与合计/均值，真实进程长跑或受控失败 |
| `Node/package.json` / `pnpm-lock.yaml` | 固定安装输入；不随业务脚本改动而更新 |

## 安装与操作

从[当前开发产物](../../Docs/DEVELOPMENT.md#development-artifacts)取得本轮宿主与测试 ZIP。使用隔离 `--profile-root`，安装 `Test.NodeEnvironmentProbe-1.1.0.zip` 后显式退出并重启；1.0.0 可直接更新，插件版本升级会准备独立的新环境。每次启动保持同一 profile 参数。

本轮可双击 `artifacts/environment-probes-20261128/Start-TestHost.cmd` 打开隔离宿主，再通过插件页安装同轮 `node/Test.NodeEnvironmentProbe-1.1.0.zip`；之后也使用该入口重启。不要使用旧夹具宿主验证本轮代码。

页面每行输入一个数值或文本，空行忽略，最多 200 行/16000 字符；运行时保存输入，重启或迁移后恢复。选择场景再点击“准备环境并执行”：

- **正常处理**：实际 npm 包逐行判断，给出有效/无效项及合计、均值；`Infinity`/`NaN` 不作为有效数值，合计溢出单独说明。默认输入有效 4 项，合计 `1035.5`、均值 `258.875`。
- **持续运行 60 秒**：同一个真实 Node 进程每秒处理一轮，输出 PID 和轮次。可切页、隐藏到托盘或查看 Packages 占用；可从本页或“日志 → 任务进度”取消。
- **预期进程失败**：Node 主动返回退出码 42，公共任务及日志应显示一次失败；这是手动选择的故障场景，切换回正常处理可重试，不应变成未捕获异常。

首次申请环境先由宿主确认，拒绝或准备失败不建立公共任务。成功准备后才登记有限任务；切页不会取消。取消会等待受管进程收尾，正常取消不记 Error。成功必须核对真实返回的版本、解释器/环境身份和逐行结果后才标完成。

每轮使用 `<插件数据目录>/Reports/<随机标识>/`，保存 `request.json` 和处理结果 `result.json`；页面显示本轮绝对路径及真实 stdout/stderr。输入只作为 JSON 数据传递，不拼成脚本。取消/失败可能留下输入或未通过完成校验的结果文件，文件存在不代表完成；插件不写入环境或缓存，也不自动删除历史结果。

## 用户验收顺序

1. 首次拒绝准备，再次运行确认后完成下载及计算；检查页面结果、实际版本/路径及 JSON 文件。
2. 选择长跑，在约 10 秒后取消并重新正常运行；再从公共任务页取消。每次均应显示取消，进程收尾后解除占用。
3. 长跑期间切换页面或隐藏到托盘，返回后轮次继续；同时运行 Python 夹具，检查任务与语言环境各自独立。显式退出停止任务，再启动不续跑。
4. 主动失败后正常重试；“预期失败”应可辨认，不能把其他错误当成该场景通过。
5. 已安装后断网，正常与长跑都应复用环境；重新联网后清理 Node 下载缓存，再断网执行，结果仍应正确。断网期间首次安装失败/取消后，恢复网络再重试。
6. Packages → Node 环境核对版本、来源、引用和路径；长跑时修复/清理应受占用保护。插件仍安装时不能清理其环境，此时先保留插件以便继续迁移测试。
7. 仅迁移隔离数据到空目录，按宿主提示退出重启。确认输入仍在、旧报告保留；再次运行显示新根的环境及报告路径，真实调用成功。中断恢复和磁盘断连需单独记录，不以正常迁移成功代替。
8. 其余场景完成后，最后卸载夹具并重启，再清理未引用环境；插件输入设置与历史报告应保留。

构建使用 [Build-Plugin](../../scripts/Build-Plugin.ps1) 与当前发布宿主 SDK。改动安装输入时须重新计算清单摘要，Git 已固定两文件 LF。构建、Review、真实界面/下载/取消/迁移结果分开记录到[验收台账](../../Docs/DEVELOPMENT.md#acceptance)。
